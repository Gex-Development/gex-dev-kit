## Kit GEX v0.3.0

A TUI virou um chat com o assistente GEX, e o kit passou a instalar plugins opcionais.

### Novidades

- **Chat no lugar das telas.** `gex-dev-kit` abre boas-vindas e depois um chat. Setup, catálogo, doctor, rollback, rollback dos agentes, git hooks e addons são fluxos desse chat. Digite `/` para abrir a paleta de comandos. A entrada fica travada enquanto o assistente escreve ou executa.
- **Setup em sete etapas:** Harness, Agentes, Destino, Extras, Plugins, Plano e Instalação. Esc ou `/voltar` volta uma etapa. As perguntas de caminho têm navegador de pastas e aceitam colar.
- **Plugins.** `caveman`, `ponytail`, `superpowers` e `spec-kit` são instalados pelo kit, no setup e em `/addons`. Antes de rodar, o chat mostra os comandos exatos e os conflitos com o Core, e só executa depois da sua confirmação. Fonte e licença ficam no card de `/addons`. Passos sem equivalente de shell ficam como instrução manual (`superpowers` no Codex e o `specify init` de cada projeto).
- **Sete skills Core obrigatórias e sete especializações opcionais**, com explicação de cada skill e hook: o que faz, quando usar e uma analogia.
- **Listas em páginas:** listas longas não rolam mais; trocam de página com as setas.

### Para saber antes de instalar

- O rollback do kit **não desfaz plugins**. Para removê-los, use o próprio Claude Code ou Codex. No Codex, aprove os hooks novos em `/hooks`.
- Plugins são código de terceiros executado na sua máquina. Revise fonte e licença antes de confirmar.
- A CLI não instala plugins; só o chat. `addons` na CLI continua sendo catálogo.
- `skills --json` usa o schema `gex-dev-kit.skills/v1`. Ele estreia nesta release e não tem campo `credentials` nas especializações: as skills de API de gateway ficaram fora do catálogo e o kit não pede nem grava chaves.
- Os testes rodam em macOS. Os binários Linux e Windows são compilados e passam por `go vet`, mas não foram exercitados em execução.

Confira `SHA256SUMS` antes de executar. Os avisos de licença das dependências estão em `THIRD_PARTY_LICENSES.txt`.
