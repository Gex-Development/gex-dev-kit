## Kit GEX v0.3.5

Novo addon de hooks, remoção de plugins e MCPs pelo chat e uma mensagem a menos.

### Novidades

- **Addon `claude-code-templates` (hooks).** Os 13 hooks pedidos: lint-on-save, smart-formatting, run-tests-after-changes, change-tracker, security-scanner, smart-commit, nextjs-code-quality-enforcer, tdd-gate, scope-guard, env-file-protection, format-javascript-files, subagent-read-only-guard e change-logger. O chat mostra o comando oficial fixado na versão 1.30.0 do pacote, com `CCT_NO_TRACKING=true` para desligar a telemetria dele. O kit **não executa** o comando: sem `--yes` o instalador pergunta onde gravar (usuário, projeto ou local), e com `--yes` só grava no projeto atual.
- **Remover plugins e MCPs.** `/addons` ganhou **Remover do Claude Code**, **do Codex** e **dos dois**, para os 9 addons. O chat mostra os comandos oficiais (`claude mcp remove`, `claude plugin uninstall`, `codex mcp remove`, `codex plugin remove`, `uv tool uninstall`), pede confirmação e trata item já removido como sucesso.

### Removido

- A mensagem `Comando equivalente: gex-dev-kit install ...` que o chat mostrava ao fim do setup, e a função que a montava.

### Para saber antes de instalar

- Os hooks do `claude-code-templates` mudam o comportamento do agente: `smart-commit` roda `git add` a cada edição, `tdd-gate` e `scope-guard` bloqueiam edições, e vários rodam formatadores e testes a cada edição. Podem se sobrepor aos hooks `gex-*`. Revise antes de instalar.
- Remover um MCP não revoga a chave: revogue no painel do fornecedor. Para o `terraform`, a imagem Docker continua no disco.
- Sem comando seguro, o chat mostra só o passo manual: hooks do caveman no Codex, hooks do `claude-code-templates` e o `.specify/` dos projetos do spec-kit.
- A remoção de MCP foi exercitada de ponta a ponta num HOME descartável. A de plugins foi testada com as mensagens reais de "não existe", mas sem instalar e remover um plugin de verdade.
- Os binários de macOS foram exercitados. Os de Linux e Windows compilam e passam por `go vet`, mas não foram exercitados em execução. O `install.ps1` também não foi executado em Windows.

Confira `SHA256SUMS` antes de executar. Os avisos de licença das dependências estão em `THIRD_PARTY_LICENSES.txt`.
