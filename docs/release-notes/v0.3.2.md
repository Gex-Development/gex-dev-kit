## Kit GEX v0.3.2

MCPs prontos para instalar pelo chat e agentes sempre na versão mais recente.

### Novidades

- **Quatro MCPs opcionais**, instalados em `/addons` e no passo Plugins do `/setup`, com os comandos exatos, os riscos e a confirmação antes de rodar: `context7` 4.4.4 (documentação atualizada de bibliotecas), `terraform` 1.4.1 (Registry do Terraform), `brave-search` 2.1.4 (busca na web) e `mapbox-devkit` 0.8.2 (mapas).
- **Agentes na versão mais recente.** O kit consulta a versão publicada do Claude Code e do Codex antes de instalar e usa `latest` nos instaladores oficiais, em vez de uma versão fixa.
- **Claude Code nativo adotado.** Um Claude Code instalado pelo instalador oficial deixa de ficar bloqueado e passa a ser atualizado pelo kit.

### Para saber antes de instalar

- **Chaves de API ficam em texto puro.** Brave Search e Mapbox exigem chave. O chat a pede em campo mascarado e o kit a grava em `~/.claude.json` e `~/.codex/config.toml`, ambos `0600`. Ela aparece na lista de processos enquanto o comando de registro roda. Reinstalar substitui a chave. O `rollback` não remove MCP nem revoga a chave: remova com `claude mcp remove --scope user NOME` e `codex mcp remove NOME`, e revogue a chave no painel do fornecedor.
- **Mapbox tem poder de escrita.** Com escopos de escrita, o agente cria e apaga estilos e tokens da conta. Crie o token com o mínimo de escopos. Exige Node.js 22 ou mais novo.
- **Terraform exige Docker ligado.** Com o Docker parado, o kit falha com clareza e não registra nada. O Terraform MCP não pede chave.
- **Context7** envia o nome da biblioteca e a pergunta ao serviço Context7.
- Só uma regra mudou sobre chaves: a de o kit não gravar chaves vale para tudo, exceto chaves de MCP.
- Sem rede, o kit não propõe atualizar um agente já registrado e bloqueia o que ainda não está registrado.
- Todos os avisos da v0.3.0 continuam valendo. Veja as [notas da v0.3.0](v0.3.0.md).

### Correções

- O Claude Code não enxergava o MCP instalado pelo kit, porque o ambiente dos addons definia `CLAUDE_CONFIG_DIR`. O MCP aparecia como instalado e não aparecia na sessão.
- O cartão do Doctor mostra primeiro os itens de atenção, e o banner diz `não instalado pelo kit` quando o kit não tem registro do agente. Com dois agentes bloqueados, cada um mostra o próprio motivo.
- Instalar só MCPs no Codex não pede mais para aprovar hooks.

### Limites desta release

- Os binários de macOS foram exercitados. Os de Linux e Windows compilam e passam por `go vet`, mas não foram exercitados em execução. O `install.ps1` também não foi executado em Windows.
- O Terraform via Docker não foi exercitado de ponta a ponta; o servidor foi testado com o binário oficial. Brave e Mapbox foram testados só com chave falsa.

Confira `SHA256SUMS` antes de executar. Os avisos de licença das dependências estão em `THIRD_PARTY_LICENSES.txt`.
