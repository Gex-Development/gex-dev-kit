## Kit GEX v0.3.3

Mensagens mais claras ao instalar plugins e MCPs, e um processo de release mais seguro.

### Novidades

- **Resultado da instalação mais claro.** O título passa a ser `Instalar plugins e MCPs`, e plugins e MCPs instalados saem em frases separadas. Quando um passo falha, o chat mostra a última linha do erro inteira, sem chaves. O cartão cortava essa linha, e o aviso do Docker desligado, por exemplo, ficava ilegível.
- **Agente bloqueado com o motivo completo.** Ao abrir o chat, o kit mostra o motivo inteiro de um Claude Code ou Codex bloqueado, por exemplo a lista de caminhos de um PATH com várias cópias. O cartão cortava essa lista.
- **README sem versão fixa.** O link aponta para a última release e a instalação manual baixa a última release por padrão. A opção de fixar a versão usa `vX.Y.Z` como marcador.

### Para quem mantém o kit

- `scripts/bump.sh` promove `[Não publicada]` a versão e atualiza versão do binário, data, link de comparação e badge.
- `scripts/release.sh` publica sem terminal com `--confirm vX.Y.Z`, a versão digitada de novo, e falha antes de compilar quando falta confirmação. Mostra quanto do limite de tamanho cada binário usa e avisa a partir de 85%.
- O `.DS_Store` que entrou por engano na v0.3.2 deixou de ser rastreado, e a imagem de social preview foi removida, porque o GitHub só a usa em repositório público.

### Para saber antes de instalar

- Nada muda em como o kit grava arquivos, chaves ou MCPs. Todos os avisos da v0.3.2 e da v0.3.0 continuam valendo: veja as [notas da v0.3.2](v0.3.2.md) e as [da v0.3.0](v0.3.0.md).
- Os binários de macOS foram exercitados. Os de Linux e Windows compilam e passam por `go vet`, mas não foram exercitados em execução. O `install.ps1` também não foi executado em Windows.

Confira `SHA256SUMS` antes de executar. Os avisos de licença das dependências estão em `THIRD_PARTY_LICENSES.txt`.
